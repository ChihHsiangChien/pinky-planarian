# Pinky Planarian Garden 🌸

一個療癒系的網頁版渦蟲養殖模擬器。結合了 Verlet 物理引擎、生物再生邏輯與馬卡龍粉色系的視覺設計，打造一個可以隨時放在口袋裡的電子水族箱。

## 🌐 線上試玩
[https://chihhsiangchien.github.io/pinky-planarian/](https://chihhsiangchien.github.io/pinky-planarian/)

## ✨ 特色功能

- **Verlet 物理模擬**：渦蟲具備柔軟、如糖果般的蠕動質感。
- **生物再生系統**：完美模擬渦蟲強大的再生能力，切斷後的每一段都能重新長成完整個體。
- **PWA 支援**：支援安裝至手機主畫面，並具備離線運行能力。
- **互動工具箱**：
  - 觀察：好奇的渦蟲會看向你的滑鼠。
  - 餵食：投餵愛心食物讓渦蟲長大。
  - 魔法棒：切割渦蟲，觀察分裂與再生。
  - 逗弄：輕戳渦蟲觀察其驚嚇反應。
  - 召喚：搖響鈴鐺吸引全場渦蟲。
  - 換水：清理髒汙，看渦蟲在水流中翻滾。
- **療癒音訊**：即時合成的 3/4 拍八音盒 BGM 與清脆的互動特效音。

## 🛠 技術棧

- **渲染**：Vanilla JavaScript + SVG (Gooey Filter)
- **物理**：Verlet Integration (Constraint-based Physics)
- **音訊**：Web Audio API (實時頻率合成)
- **部署**：GitHub Pages + PWA (Service Worker)

## 📖 操作說明

1. **進入網頁後點擊任何地方**：啟動音訊引擎與八音盒音樂。
2. **切換模式**：使用上方的控制面板切換互動工具。
3. **換水時機**：當背景變綠、渦蟲活動力下降時，請及時換水。

## 📸 視覺設計

採用 **Cherry Blossom Pink (#ffb7c5)** 作為生物主色調，搭配 **Water Blue (#b2ebf2)** 的清澈背景。眼睛設計為經典的「鬥雞眼」樣式，增加呆萌感。
